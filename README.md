# JavaScript Date and Time

A JavaScript practice project focused on working with dates and times and displaying them in different formats.

## 🚀 Features

- Display dates in multiple formats
- Display time in 12-hour and 24-hour formats
- Show day names
- Show month names
- Format dates using JavaScript
- Add leading zeros to hours and minutes
- Practice different date and time formatting techniques

## 📅 Date & Time Formats

The project demonstrates formats such as:

```text
Wed 24-Apr 7:45 PM
April 5th 07:45 PM
04/20/2024 13:45:30
Thu 20/4/2024 13.45
2024-04-20 3:45 Thursday
April 20th, 2024 01.45.30 PM
20 April 2024 at 01:45 PM
```
